Telegram-бот для организации учебного процесса.
1) найдите бота в Telegram и введите команду "/start";
2) используйте меню или команды:
- /task_... - задачи;
- /event_... - события;
- /schedule_... - расписание;
3) следуйте подсказкам бота;
4) просматривайте и редактируйте созданные элементы через текстовые команды;
5) получайте автоматические напоминания о важных мероприятиях.
